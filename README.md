# LEVI POS — معاينة الواجهة

نسخة ثابتة للعرض فقط من واجهة LEVI POS:

- `index.html` — صفحة الدخول (564 × 622، البطاقة 436 × 493).
- `dashboard.html` — القائمة الجانبية ولوحة التحكم (1264 × 683).
- `styles.css` — الألوان والتنسيق المعتمد.

لا تحتوي على PHP ولا قاعدة بيانات، والأزرار للعرض فقط.
بيانات العرض: `admin` / `admin123`.
